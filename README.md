# UAS Kriptografi - PKI Interactive Simulator

Eye-catching terminal tool with short role names (CA, RA, Cust) + fun ASCII art.

## Quick Start
```bash
git clone https://github.com/OnlyOneArthur/UAS-kriptografi-sms-4.git
cd UAS-kriptografi-sms-4
git checkout pki-roleplay-simulation
pip install -r requirements.txt
python pki_uas_simulation.py
```

## Features
- Short names: CA, RA, Cust1, Cust2, Cust3
- Beautiful box-drawing UI + colors
- Interactive menu (choose what to demo)
- Real RSA-2048 + X.509 certificates
- ASCII art (dog ngopi style on exit)
- All required role-play scenarios covered

## Menu
1. Initialize CA + RA  
2. Register Cust1/2/3  
3. Show status  
4-8. Individual scenarios  
9. Full run  
0. Exit (with ASCII art)

Good luck with your UAS! Make it stand out.
